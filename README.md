# 🦊 Brownux

Rust programlama dili ve Servo motoru üzerine inşa edilmiş, hafif, hızlı ve gizlilik odaklı Android internet tarayıcısı.

## ✨ Özellikler
* **Servo Motoru:** Google (Blink) veya Mozilla (Gecko) şişkinliği olmadan, tamamen Rust ile yazılmış modern render motoru.
* **Yerleşik Reklam Engelleyici:** Eklenti gerektirmez. `adblock-rust` entegrasyonu sayesinde reklamlar ve izleyiciler daha ağ katmanında engellenir.
* **Material You (Material 3):** Android'in dinamik renk paletine tam uyumlu, kenardan kenara modern arayüz.
* **Hafiflik:** Gereksiz özelliklerden arındırılmış, düşük RAM ve işlemci tüketimi.

## 🚀 Derleme ve Kurulum
Bu proje GitHub Actions kullanılarak otomatik derlenir. 
Kendi APK dosyanı oluşturmak için:
1. **Actions** sekmesine git.
2. **Brownux Build** iş akışını seç.
3. **Run workflow** butonuna tıkla.
4. Derleme bittiğinde **Artifacts** kısmından APK'yı indir.

## 📝 Durum
Proje şu anda aktif geliştirme (Alpha) aşamasındadır. Çekirdek Servo entegrasyonu ve arayüz geliştirmeleri devam etmektedir.
